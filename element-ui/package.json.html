# main

项目的入口文件。

"main": "lib/element-ui.common.js"
  • lib/element-ui.common.js，JS是commonjs规范（node平台）

# files

指定 npm publish 发包时，需要包含的文件/目录

"files": [
    "lib",
    "src",
    "packages",
    "types",
    "web-types.json"
],

# typings

TypeScript入口文件。

"typings": "types/index.d.ts"

# unpkg

当你把一个包发布到 npm 上时，它同时应该也可以在 unpkg 上获取到。

也就是说，你的代码既可能在NodeJs环境也可能在浏览器环境执行。为此你需要用umd格式打包，lib/index.js是umd规范，由webpack.conf.js生成。

"unpkg": "lib/index.js"

# style

声明样式入口文件

"style": "lib/theme-chalk/index.css"

# web-types

是一种与框架无关的格式。用于为IDE和其他工具，提供有关组件库（component library）内容的元数据信息。

"web-types": "./web-types.json"

# scripts

通过 npm run <script>执行脚本

# bootstrap

yarn || npm i

# build:file

自动化生成文件（工程化）

node build/bin/iconInit.js & 
node build/bin/build-entry.js & 
node build/bin/i18n.js & 
node build/bin/version.js

  • iconInit.js

    解析icon.scss，把所有的icon的名字放在icon.json里面，最后挂在Vue原型上的$icon上。

  • build-entry.js

    根据components.json文件，生成src/index.js文件（项目的入口文件），核心就是json-templater/string插件的使用。

  • i18n.js

    根据 examples/i18n/page.json 和*.tpl模版，生成不同语言的 demo，也就是官网demo展示国际化的处理。

  • version.js

    根据package.json中的version,生成examples/versions.json，对应就是完整的版本列表。

# build:theme

处理样式

node build/bin/gen-cssfile && 
gulp build --gulpfile packages/theme-chalk/gulpfile.js && 
cp-cli packages/theme-chalk/lib lib/theme-chalk

  • gen-cssfile

    根据components.json，生成package/theme-chalk/index.scss文件，把所有组件的样式都导入到index.scss。

  • gulpfile.js

    ElementUI支持全局引入和按需引入。

    采用gulp工作流，将packages/theme-chalk下的所有scss文件编译为css，

    • 当你需要全局引入时，就去引入index.scss文件；
    • 当你按需引入时，引入对应的组件scss文件即可。

  • cp-cli

    它是一个跨平台的cope工具，和CopyWebpackPlugin类似。

    cp-cli packages/theme-chalk/lib lib/theme-chalk

    将 packages/theme-chalk/lib 文件复制到 lib/theme-chalk
