# jQuery的无new构建原理

  • 没有采用new操作符；
  • return返回的是一个通过new出来的的对象 。

# new操作符构建对象

new操作符主要是把原型链跟实例的this关联起来，这才是最关键的一点。

通过new操作符构建一个对象，一般经过四步：

A.创建一个新对象

B.将构造函数的作用域赋给新对象（所以this就指向了这个新对象）

C.执行构造函数中的代码

D.返回这个新对象

  • 达成目标

# 1. 通过构造函数实现类

// 声明一个构造函数 mQuery
function Query() {
}

// 添加属性或方法
Query.prototype.init = function(){
   console.log('run init...')
}

// new生成一个对象
var oQuery = new Query();

// 调用init
oQuery.init();

# 2. 创建对象的同时调用init方法

- var oQuery = new Query()
- oQuery.init()
+ new Query.prototype.init();

# 3. 实现无new调用init方法

  function Query() {
+   return new Query.prototype.init();
  }
  Query.prototype.init = function(){
    console.log('run init...')
  }

  • 创建一个实例对象

    Query();   // 这是不是和我们调用 $()或jQuery() 很像了

# 4. 给原型添加方法

  function Query() {
    return new Query.prototype.init();
  }
  Query.prototype.init = function(){
    console.log('run init...')
  }
+ Query.prototype.css = function(){
+   console.log('run css...')
+ }

  • 我们把上在添加原型方法或属性，做一个合并

      function Query() {
    return new Query.prototype.init();
  }
+ Query.prototype = {
+   init: function(){ console.log('run init...'); },
+   css: function() { console.log('run css...'); }
+ }
- Query.prototype.init = function(){
-   console.log('run init...')
- }
- Query.prototype.css = function(){
-   console.log('run css...')
- }

  • 上面代码，有一个比较严重的问题，因为它是完全覆盖prototype来实现的，会把prototype原型上的 constructor 方法覆盖：

      function Query() {
    return new Query.prototype.init();
  }
  Query.prototype = {
+   constructor: Query,
    init: function(){ console.log('run init...'); },
    css: function() { console.log('run css...'); }
  }

    • 这样，我们就完美实现了 ptototype 的合并。

      接上来，我们来像jQuery中一样，调用css() 方法：

    Query().css();

  • 结果，报错了：

    Uncaught TypeError: Query(...).css is not a function

# 5. 🎉无法调用css()

​ 在 Query() 构造函数中，执行的是init() 方法，如果我们把 Query.prototype 的原型挂载到init() 上，那是不是就可以通过原型链来调用css()方法了？

  function Query() {
    return new Query.prototype.init();
  }
  Query.prototype = {
    constructor: Query,
    init: function(){ console.log('run init...'); },
    css: function() { console.log('run css...'); }
  }
+ Query.prototype.init.prototype = Query.prototype;

  • 再来执行一下css()，看一下效果：

    Query().css(); // everything is OK

# 6. 代码优化

  • 方法代码压缩，给 Query.prototype 定义一个变量：
  function Query() {
-   return new Query.prototype.init();
+   return new Query.fn.init();
  }
- Query.prototype = {
+ Query.fn = Query.prototype = {
    constructor: Query,
    init: function(){ console.log('run init...'); },
    css: function() { console.log('run css...'); }
  }
- Query.prototype.init.prototype = Query.prototype;
+ Query.fn.init.prototype = Query.fn;

# 7. 模块化

通过IIFE 来实现模块化，并对外暴露全局变量：

+ (function(window, undefined){
    function Query() {
      return new Query.fn.init();
    }
    Query.fn = Query.prototype = {
      constructor: Query,
      init: function(){ console.log('run init...'); },
      css: function() { console.log('run css...'); }
    }
    Query.fn.init.prototype = Query.fn;
+   window.mQuery = window.$$ = Query;
+ })(window);

如此，便实现了jQuery 中的 无new构建对象

$$()
mQuery()

$$().css()
mQuery().css()
