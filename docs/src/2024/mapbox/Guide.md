### Turf

[Turf](https://turfjs.org/) is a JavaScript library for [spatial analysis](https://en.wikipedia.org/wiki/Spatial_analysis). It includes traditional spatial operations, helper functions for creating [GeoJSON](https://geojson.org/) data, and data classification and statistics tools. Turf can be added to your website as a client-side plugin, or you can [run Turf server-side](https://www.npmjs.com/package/@turf/turf) with [Node.js](https://nodejs.org/) (see below).

Turf是一个空间分析的JS库。它包括传统的空间操作、用于创建GeoJSON的辅助函数数据以及数据分类和统计工具。Turf可以作为客户端插件添加到您的网站，也可以使用Node.js在服务器端运行Turf（见下文）。
