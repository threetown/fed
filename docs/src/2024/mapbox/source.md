## Source

在Mapbox中，`sources` 是地图数据源的集合，是创建交互式Web地图应用程序时不可或缺的一部分。以下是关于 `sources` 的详细解释：

### 一、定义

`sources` 是Mapbox中用于包含一系列数据源（`source`）的对象。这些数据源提供了在地图上显示的数据。每个 `source` 都有一个 `type` 属性，用于指定其具体的类型。

### 二、sources的类型

Mapbox支持多种类型的数据源，包括但不限于以下几种：

1. Vector（矢量数据）

   ：

   - 描述：用于表示点、线、面等矢量数据，通常通过GeoJSON数据格式表示。
   - 示例：用于显示地图上的道路、行政区划、建筑物等。

2. Raster（栅格数据）

   ：

   - 描述：常见的瓦片地图，如影像数据。
   - 示例：用于显示卫星图像、航拍图像等。

3. GeoJSON

   ：

   - 描述：基于JSON的Geo数据格式，用于表示点、线、面等矢量数据。
   - 示例：直接加载GeoJSON文件作为地图数据源。

4. Image（图像数据）

   ：

   - 描述：图像数据源，如照片、影像等。
   - 示例：用于在地图上叠加特定的图像。

5. Video（视频数据）

   ：

   - 描述：视频数据源，如视频流等。
   - 示例：在地图上嵌入实时监控视频。

### 三、格式与结构

`sources` 是以对象 `{}` 的形式存在的，其属性名就是数据源的名称（或说数据源的ID）。这样，可以根据数据源的名称快速获取数据源的信息。

### 四、使用方式

在Mapbox中，通常先创建好数据源（即定义 `sources`），然后将数据源以Layer的形式添加到地图上。Layer用于定义数据的呈现样式，可以绑定到不同的Source上。

### 五、示例

以下是一个简单的示例，展示了如何在Mapbox中定义一个Vector类型的数据源：

```json
"sources": {  
  "my-vector-source": {  
    "type": "vector",  
    "tiles": ["http://example.com/tiles/{z}/{x}/{y}.pbf"],  
    "minzoom": 0,  
    "maxzoom": 14  
  }  
}
```

在这个示例中，`my-vector-source` 是数据源的名称，`type` 指定了数据源的类型为 `vector`，`tiles` 属性指定了瓦片数据的URL模板，`minzoom` 和 `maxzoom` 分别指定了数据源的最小和最大缩放级别。
