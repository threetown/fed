# 样式

样式的方案有很多种：

* CSS custom properties (variables)：CSS自定义属性或CSS变量
* Less
* Sass
* TailwindCSS
* UnoCSS

这里我们在组件库中使用`scss`预处理语言（参考：element-ui的样式）。



## theme-chalk

参考`element-theme-chalk`，给`demo`组件创建样式文件：

```bash
.
└── packages
    ├── ...
    └── theme-chalk
        └── src
            └── demo.scss
```

由于`.scss` 文件最终需要处理成`.css`才能被浏览器识别，所以我们引入 **scss**依赖处理成**css**。



## gulp

将scss编译成css，使用**gulp** （自动化构建工具，它基于`Node`流的能力去构建任务流的，某些方面上更具性能优势，相对于webpack更纯粹）工作流。它需要经过以下几步：

* 将SCSS转换成 CSS：`gulp-scss`
* 自动补全CSS前缀：`gulp-autoprefixer`
* 压缩CSS：`gulp-cssmin`

需要用到4个依赖包：

```bash
yarn add gulp@4.0.2 gulp-sass@4.0.2 gulp-autoprefixer@6.0.0 gulp-cssmin@0.2.0 -D
```

### gulpfile.js

* `packages/gulpfile.js`

```js
'use strict';

const { series, src, dest } = require('gulp');
const sass = require('gulp-sass');
const autoprefixer = require('gulp-autoprefixer');
const cssmin = require('gulp-cssmin');

function compile() {
  return src('./src/*.scss')
    .pipe(sass.sync())
    .pipe(autoprefixer({
      browsers: ['ie > 9', 'last 2 versions'],
      cascade: false
    }))
    .pipe(cssmin())
    .pipe(dest('./lib'));
}

exports.build = series(compile);

```



### build:theme

在`package.json`中创建 `build:theme` 脚本：

```json
"build:theme": "gulp build --gulpfile packages/theme-chalk/gulpfile.js"
```

执行`build:theme`命令后，会看到`packages/theme-chalk`目录下多了一个`lib/demo.css`

```bash
$ tree packages
packages
├── demo
│   ├── index.js
│   └── src
│       └── main.vue
└── theme-chalk
    ├── gulpfile.js
    ├── lib
    │   └── demo.css
    └── src
        └── demo.scss

```

### cp-cli

此时，我们得到的 **CSS** 在 `packages/theme-chalk/lib/*.css`中，但我们使用 **element-ui** 样式是按下面方式引入的：

```js
import 'element-ui/lib/theme-chalk/index.css';
```

即：在`element-ui`文件夹下的`index.css`。

因此，我们找到 `element-ui` 源码中的`packages/theme-chalk/src/index.scss`。

```scss
@import "./base.scss";
@import "./pagination.scss";
// ...
```

所以，我们创建一个`theme-chalk/src/index.scss`样式文件，并引入`demo.scss`

```scss
@import "./demo.scss";
```

执行 `yarn build:theme` 就会生成`index.css`。

但，我们发现element-ui样式是引入**根目录**下的`lib`文件。所以，接下来我们需要将`packages/theme-chalk/lib/index.css` 移动到 `lib/theme-chalk/index.css`中。

移动文件，我们需要使用`cp-cli`：

```bash
yarn add cp-cli@1.0.2 -D
```

并修改`theme:build`脚本：

```diff
- gulp build --gulpfile packages/theme-chalk/gulpfile.js
+ gulp build --gulpfile packages/theme-chalk/gulpfile.js && cp-cli packages/theme-chalk/lib lib/theme-chalk
```

执行脚本：`yarn build:theme` 即可将 **css** 移动到`lib/theme-chalk`目录下。 



## SCSS

我们参考`element-ui`的样式文件目录结构，复制样式文件：

* 项目主题定义：`common/var.scss`
* 定义一些变量，如，项目标识`tt`及样式 **BEM（Block Element Modifier，块级元素修饰符）**规范：`mixins/config.scss`
* scss函数：`mixins/function.scss`
* 具有相同性质的混入：`mixins/mixins.scss`

```bash
$ tree packages/theme-chalk/src
packages/theme-chalk/src
├── common
│   └── var.scss
├── demo.scss
├── index.scss
└── mixins
    ├── config.scss
    ├── function.scss
    └── mixins.scss
```

接下来，对`demo.scss`进行改造：

```scss
@import "common/var";
@import "mixins/mixins";

@include b(button) {
  background: $--button-default-background-color;
  color: $--button-default-font-color;
  border-color: $--button-default-border-color;
  border-radius: 3px;
  box-shadow: 0 6px 18px 0 rgba(232, 237, 250, .5);
}

```
