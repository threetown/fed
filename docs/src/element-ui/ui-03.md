# gen-cssfile

前面我们已经了解到，组件样式需要以下几点：

* 创建组件样式：`<component>.scss`
* Index.scss导入`<component>.scss`

为了提高效率，将注意力放在组件开发本身，我们可以通过自动化处理。参考`element-ui`的`gen-cssfile.js`。

## bin

创建`build/bin/gen-cssfile.js`，并给`build:theme`脚本增加命令：

```diff
- gulp build --gulpfile packages/theme-chalk/gulpfile.js && cp-cli packages/theme-chalk/lib lib/theme-chalk
+ node build/bin/gen-cssfile && gulp build --gulpfile packages/theme-chalk/gulpfile.js && cp-cli packages/theme-chalk/lib lib/theme-chalk
```



## gen-cssfile.js

在`element-ui`中`build/bin/gen-cssfile.js`源码中，它做了2件事：

* 通过 `components.json` 遍历组件，判断是否存在样式文件，没有则创建组件样式
* 遍历将组件样式`@import` 引入到`index.scss`中

```js
var fs = require('fs');
var path = require('path');
var Components = require('../../components.json');
var themes = [
  'theme-chalk'
];
Components = Object.keys(Components);
var basepath = path.resolve(__dirname, '../../packages/');

function fileExists(filePath) {
  try {
    return fs.statSync(filePath).isFile();
  } catch (err) {
    return false;
  }
}

themes.forEach((theme) => {
  var isSCSS = theme !== 'theme-default';
  var indexContent = isSCSS ? '@import "./base.scss";\n' : '@import "./base.css";\n';
  Components.forEach(function(key) {
    if (['icon', 'option', 'option-group'].indexOf(key) > -1) return;
    var fileName = key + (isSCSS ? '.scss' : '.css');
    indexContent += '@import "./' + fileName + '";\n';
    var filePath = path.resolve(basepath, theme, 'src', fileName);
    if (!fileExists(filePath)) {
      fs.writeFileSync(filePath, '', 'utf8');
      console.log(theme, ' 创建遗漏的 ', fileName, ' 文件');
    }
  });
  fs.writeFileSync(path.resolve(basepath, theme, 'src', isSCSS ? 'index.scss' : 'index.css'), indexContent);
});

```

### components.json

在根目录创建`code components.json`，内容如下：

```json
{
    "demo": "./packages/demo/index.js",
    "loading": "./packages/loading/index.js"
}
```



### base.scss

在创建 `index.scss`时，引入了`packages/theme-chalk/src/base.scss`；

```js
  var indexContent = isSCSS ? '@import "./base.scss";\n' : '@import "./base.css";\n';
```

我们来看一下 `base.scss` 文件内容：

```scss
@import "common/transition.scss";
@import "icon.scss";
```

分别是动画效果（`common/transition.scss`）和Icon图标样式，下面来看一样`icon.scss`



### icon.scss

> 注意：`font-family`为`threetowns-icons`、`[class^="tt-icon-"], [class*=" tt-icon-"]`

主要看一下 `@font-face` 部分：

```scss
@font-face {
  font-family: 'threetowns-icons';
  src: url('#{$--font-path}/threetowns-icons.woff') format('woff'), /* chrome, firefox */
       url('#{$--font-path}/threetowns-icons.ttf') format('truetype'); /* chrome, firefox, opera, Safari, Android, iOS 4.2+*/
  font-weight: normal;
  font-display: $--font-display;
  font-style: normal;
}

[class^="tt-icon-"], [class*=" tt-icon-"] {
  /* use !important to prevent issues with browser extensions that change fonts */
  font-family: 'threetowns-icons' !important;
  // ...
}

.tt-icon-ice-cream-round:before {
  content: "\e6a0";
}
// ...
```

在`common/var` 中，可以找到  **$--font-path**的指向  `$--font-path: 'fonts' !default;` 

所以，我们将 `packages/theme-chalk/src/fonts` 复制一份到项目中（注意是否需要自定义font-family）



至此，执行 `yarn build:theme` 就会自动根据`components.json`构造样式文件。

但还是有个问题，在最终的 **lib/theme-chalk**下无 `fonts`。所以，我们需要对`fonts`复制一份。

```diff
+ function copyfont() {
+   return src('./src/fonts/**')
+    .pipe(cssmin())
+    .pipe(dest('./lib/fonts'));
+ }

- exports.build = series(compile);
+ exports.build = series(compile, copyfont);
```





## 总结

至此，我们通过`build/bin/gen-cssfile.js`根据`components.json`自动创建**遗漏**的 **scss** 样式。其中，对`icon.scss`处理时直接`coypfont`
